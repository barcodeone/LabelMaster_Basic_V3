━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📌 지원되는 파일 형식
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ .xlsx  (Excel 2007 이상) ⭐ 권장
   - 가장 안정적이고 모든 기능 지원
   - Excel에서 "Excel 통합 문서 (*.xlsx)" 형식으로 저장

✅ .xls   (Excel 97-2003)
   - 구 버전 Excel 호환용
   - Excel에서 "Excel 97-2003 통합 문서 (*.xls)" 형식으로 저장

✅ .csv   (쉼표로 구분된 텍스트)
   - 간단한 데이터 전용 (서식 없음)
   - Excel에서 "CSV (쉼표로 분리) (*.csv)" 형식으로 저장


❌ 지원되지 않는 형식
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✖ .xlsm (매크로 포함 파일)
✖ .xlsb (이진 통합 문서)
✖ .xltx, .xlt (템플릿 파일)

→ 해결: Excel에서 .xlsx 형식으로 다시 저장하세요


📊 엑셀 파일 구조 예시
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

| 바코드    | 품명      | 가격      | 비고          |
|-----------|-----------|-----------|---------------|
| 12345     | 사과      | 10000     | 국산          |
| ABC123    | 배        | 20000     | 유기농        |

✓ 1행: 헤더(컬럼명) 필수
✓ 2행부터: 실제 데이터
✓ 가격은 숫자만 입력 (프로그램 서식에서 '원화' 체크 시 ₩ 기호 및 천 단위 콤마 자동 적용)


🎯 파일 불러오기 방법
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

방법 1: 버튼 클릭
  1. 상단 메뉴 "엑셀 출력" 클릭
  2. "엑셀 열기" 버튼 클릭
  3. 파일 선택

방법 2: 드래그 앤 드롭 ⭐ 추천
  1. 탐색기에서 엑셀 파일 선택
  2. 프로그램 창으로 드래그하여 놓기
  3. 자동으로 엑셀 모드 전환


⚠️ 문제 해결
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

문제: 파일이 열리지 않음
→ Excel에서 파일을 닫고 다시 시도
→ "다른 이름으로 저장"으로 .xlsx 형식으로 저장

문제: 암호로 보호된 파일
→ Excel에서 암호 보호 해제 후 저장

문제: 데이터가 안 보임
→ 1행에 헤더(컬럼명)가 있는지 확인
→ 첫 번째 워크시트에 데이터가 있는지 확인

문제: 호환성 오류 (AlternateContent 오류)
→ Excel에서 파일 열기
→ "다른 이름으로 저장" → "Excel 통합 문서 (*.xlsx)" 선택

• 컬럼 설정은 자동 저장되므로 한 번만 설정하면 됩니다
• 가격 컬럼은 프로그램 내 항목 서식에서 '원화'를 체크하면 원화(₩) 기호 및 천 단위 콤마가 자동 적용됩니다
• 여러 컬럼을 한 라벨에 동시 출력할 수 있습니다
