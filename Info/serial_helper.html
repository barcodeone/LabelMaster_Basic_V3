구글 드라이브 연동 가이드

  • 최초 설정: Google API 및 자격증명 설정을 클릭하여 Client ID와 API Key를 입력하세요.
  • 연동(OAuth): 구글 계정 연결을 클릭하면 팝업 로그인 창을 통해 구글 계정과 연결됩니다.
  • 수동 연결: 로컬 샌드박스 보안상 자동 로그인이 원활치 않을 경우, OAuth Playground 등에서 발급받은 임시 액세스 토큰을 수동 주입하여 즉시 드라이브에 접근할 수 있습니다.
  • 덮어쓰기: 드라이브에서 가져오기를 수행하면 해당 파일 ID가 자동 기억되어, 드라이브 저장 시 기존 드라이브 파일에 그대로 덮어쓰기됩니다.
