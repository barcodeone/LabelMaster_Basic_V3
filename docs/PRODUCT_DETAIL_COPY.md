### [CORE FEATURE 01 : 엑셀 대량 인쇄 (최대 10,000행)]
**엑셀 파일 드래그 & 드롭 한 번으로 10,000행 초고속 대량 인쇄!**

- **헤더 자동 감지**: 엑셀 1행의 제목(품명, 바코드, 가격 등)을 자동으로 인식하여 클릭 한 번으로 매칭
- **대용량 논스톱 스트리밍**: 10,000행 데이터도 UI 멈춤 없이 쾌적하고 부드럽게 비동기 출력
- **다양한 출력 옵션**:
  - `전체 일괄 출력` : 모든 행을 순차적으로 초고속 자동 출력
  - `선택 행 출력` : 원하는 행만 체크박스로 골라 출력
  - `구간 지정 출력` : "50번부터 200번까지" 필요한 부분만 정밀 출력
  - `매수 지정` : 각 품목당 동일 수량(1장, 2장 등) 반복 인쇄

### [CORE FEATURE 02 : 1:1 WYSIWYG 캔버스 마우스 드래그 편집]
**화면에 보이는 그대로 100% 인쇄되는 직관적인 WYSIWYG 캔버스!**

- **마우스 드래그 배치**: 좌표 수치 입력 없이 마우스로 텍스트와 바코드를 원하는 위치로 이동
- **우측 핸들 폭(너비) 조절**: 핸들을 좌우로 드래그하여 긴 상품명도 원하는 폭에서 깔끔하게 자동 줄바꿈
- **원클릭 서식 제어**: 글꼴(FontFamily), 글자 크기 증감(+/-), 굵게(Bold), 기울임(Italic), 원화(₩) 기호 및 천 단위 콤마 자동 적용
- **서식 파일 저장/불러오기**: 한 번 맞춰둔 디자인은 `*.lbm` 파일로 저장하여 다음 작업 시 1초 만에 로드

### [CORE FEATURE 03 : 바코드 7종 & 일련번호/날짜/표 모드]
**온라인 유통부터 오프라인 매장, 공장 부품 식별까지 완벽 지원!**

- **1D / 2D 바코드 7종 지원**:
  - `QR Code` : 스마트폰 스캔용 URL 및 제품 상세 정보
  - `Code 128` : 쿠팡, 물류, 재고 관리용 표준 바코드
  - `EAN-13` : 대형마트, 편의점 등 국제 유통 표준 상품 바코드
  - `Code 39` : 자동차, 전자, 국방 등 제조 산업 표준
  - `ITF-14` : 골판지 박스 물류용 외포장 바코드
  - `Data Matrix` : 반도체, 초소형 부품, 의약품용 초소형 2D 바코드
  - `PDF-417` : 신분증, 항공권, 대용량 데이터 바코드
- **스마트 시퀀스 & 날짜 자동 인쇄**:
  - 출력할 때마다 `0001`, `0002`... 번호가 자동 증가하는 일련번호(Serial)
  - 인쇄 시점의 실시간 날짜/시간(DateTime) 자동 표기
- **표(Table) 테두리 모드 지원**:
  - KC인증표, 식품 영양성분표, 규격 라벨 표 테두리 완벽 구현

### [FAQ : 자주 묻는 질문]

**Q1. 엑셀 파일 컬럼 순서나 제목이 제각각이어도 쓸 수 있나요?**  
> 네! 첫 행의 컬럼 제목을 프로그램이 자동 인식하므로, 드롭다운에서 원하는 항목만 골라 매핑하시면 됩니다. 한 번 설정한 매핑은 자동 보관됩니다.

**Q2. 컴퓨터에 프로그램을 설치해야 하나요?**  
> 설치 과정이 없는 단일 포터블(Portable) 무설치 파일입니다. USB에 담아서 어느 PC에서나 즉시 실행 가능합니다.

**Q3. 라벨 용지 규격 제한이 있나요?**  
> 30x20mm 초소형 라벨부터 100x150mm 택배 송장 규격까지 밀리미터(mm) 단위로 자유롭게 용지 크기와 방향을 설정할 수 있습니다.
