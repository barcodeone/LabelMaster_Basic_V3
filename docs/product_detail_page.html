FAQ

자주 묻는 질문

궁금하신 점을 빠르게 확인해 보세요.

Q 엑셀 파일의 양식이나 컬럼 위치가 제각각이어도 쓸 수 있나요?
네, 전혀 문제없습니다! LabelMaster는 엑셀 1행의 컬럼 제목을 자동으로 인식하므로, 드롭다운 메뉴에서 '바코드', '상품명', '가격' 등 원하는 컬럼을 클릭 한 번으로 매핑하시면 됩니다. 한 번 설정한 매핑은 자동 저장됩니다.
Q 설치 과정이 복잡하거나 컴퓨터가 느려지지 않나요?
복잡한 설치 마법사나 레지스트리 등록이 없는 단일 포터블(Portable) 무설치 구조입니다. USB 메모리에 담아서 다른 PC에 꽂아도 즉시 실행할 수 있을 만큼 가볍고 쾌적합니다.
Q Xprinter 이외의 다른 라벨 프린터에서도 사용할 수 있나요?
본 프로그램은 Xprinter TSPL(열전사/감열 표준 제어어) 명령에 최적화되어 있습니다. TSPL 표준 프로토콜을 지원하는 라벨 프린터라면 뛰어난 호환성을 제공합니다.
Q 라벨 용지 크기(가로/세로)를 자유롭게 변경할 수 있나요?
네! 30x20mm 초소형 라벨부터 100x150mm 대형 택배 송장 라벨까지 밀리미터(mm) 단위로 완벽하게 용지 크기와 방향(가로/세로), 여백을 자유롭게 설정할 수 있습니다.
Q 프로그램 업데이트나 기능 개선은 어떻게 이루어지나요?
정품 라이선스 구매 고객님께는 성능 개선, 신규 기능 추가, 버그 패치가 포함된 정기 업데이트가 지속적으로 제공됩니다.
