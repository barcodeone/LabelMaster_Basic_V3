1. 핵심 주요 기능 안내
--------------------------------------------------------------------------------
1. 1:1 실시간 인터랙티브 WYSIWYG 미리보기 & 마우스 드래그 조작
   - 텍스트, 바코드, 순번, 날짜 요소를 마우스로 자유롭게 배치 (Drag & Drop)
   - [우측 크기조절 핸들]: 마우스로 핸들을 좌우로 당겨 줄바꿈 박스 너비 실시간 조절
   - 폰트 종류, 크기(+/-), 굵게(B), 기울임(I), 정렬, 원화(₩) 금액 서식 지원
   - 라벨 용지 크기(mm 단위) 및 90도 단위 회전(0°/90°/180°/270°) 지원

2. 대용량 엑셀(Excel) 데이터 자동 연동 인쇄
   - 엑셀 파일(.xlsx, .xls, .csv)을 프로그램 창으로 드래그 & 드롭하여 즉시 로드
   - 1행 헤더 자동 인식 및 항목 1~8번 컬럼 원클릭 스마트 매핑
   - 최대 10,000행 대용량 데이터도 UI 멈춤 없는 비동기 스트리밍 출력
   - [선택 행 출력] / [구간(시작~끝) 출력] / [전체 일괄 출력] 지원

3. 산업 표준 바코드 7종 & 일련번호/날짜/표 모드
   - 바코드 규격: QR Code, Code 128, EAN-13, Code 39, ITF-14, Data Matrix, PDF-417
   - [순번(Serial)]: 출력할 때마다 번호 자동 카운트 (1, 01, 001, No.1 등 8종 서식)
   - [날짜/시간(DateTime)]: 현재 일자 및 시간을 원하는 형식으로 자동 인쇄
   - [표(Table) 테두리 모드]: KC인증표, 성분표, 가격표 규격 테두리 완벽 구현

4. 디자인 서식 템플릿 파일(*.lbm) 관리
   - 공들여 설정한 용지 규격과 폰트, 바코드 디자인을 파일로 저장 및 복원
   - 마지막 작업 설정은 프로그램 종료 시에도 자동 보관

5. Xprinter 하드웨어 최적화 제어
   - USB 케이블 연결 즉시 자동 기기 감지
   - 라벨 밀림 방지 원클릭 용지 센서 자동 보정(Calibration)
   - 인쇄 농도(Darkness 1~15) 및 인쇄 속도 미세 조절 지원

--------------------------------------------------------------------------------
2. 초간단 퀵 스타트 가이드 (★ 사용 전 필수 확인)
--------------------------------------------------------------------------------
[사전준비] ★ Xprinter 공식 Windows 프린터 드라이버를 먼저 PC에 설치해야 합니다!
          (드라이버가 설치되어 있어야 프로그램에서 프린터가 정상 인식됩니다)

[1단계] 좌측 상단에서 용지 크기(너비 x 높이 mm)를 실제 라벨과 맞춥니다.
[2단계] 엑셀 파일(.xlsx)을 프로그램 창으로 끌어다 놓아 컬럼을 매칭합니다.
[3단계] 하단의 [전체 출력] 또는 [선택 출력] 버튼을 클릭하면 초고속 출력 시작!

3. 자주 묻는 질문 (FAQ) & 팁
--------------------------------------------------------------------------------
Q. 상단 목록에 프린터가 나타나지 않아요!
A. Xprinter 공식 Windows 드라이버가 PC에 설치되어 있는지 확인해 주세요.
   드라이버 설치 및 USB 케이블 연결 후 상단 우측의 새로고침(🔄)을 누르시면 감지됩니다.

Q. 라벨 위치가 한쪽으로 밀려 나오거나 간격이 안 맞아요!
A. 상단 [⚙️ 프린터 설정] > [📏 센서 보정 (캘리)]를 누르면 프린터가 용지 간격을
   자동으로 인식하여 정상 정렬됩니다. (새 용지 장착 시 필수)

Q. 바코드가 흐리거나 스캐너가 인식을 못해요!
A. [⚙️ 프린터 설정]에서 인쇄 농도(Darkness)를 10~12 정도로 올려주세요.

Q. 엑셀 파일이 열리지 않아요!
A. 현재 Excel 프로그램에서 해당 파일을 열어두고 계신 경우 닫은 후 다시 시도하시거나,
   엑셀에서 "다른 이름으로 저장" > "Excel 통합 문서 (*.xlsx)"로 다시 저장해 주세요.
