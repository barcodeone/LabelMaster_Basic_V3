2. 초간단 퀵 스타트 가이드 (★ 사용 전 필수 확인)
--------------------------------------------------------------------------------
[사전준비] ★ 프린터 제조사 공식 Windows 프린터 드라이버를 먼저 PC에 설치해야 합니다!
          (드라이버가 설치되어 있어야 프로그램에서 프린터가 정상 인식됩니다)

[1단계] 좌측 상단에서 용지 크기(너비 x 높이 mm)를 실제 라벨과 맞춥니다.
[2단계] 엑셀 파일(.xlsx)을 프로그램 창으로 끌어다 놓아 컬럼을 매칭합니다.
[3단계] 하단의 [전체 출력] 또는 [선택 출력] 버튼을 클릭하면 초고속 출력 시작!

3. 자주 묻는 질문 (FAQ) & 팁
--------------------------------------------------------------------------------
Q. 상단 목록에 프린터가 나타나지 않아요!
A. Windows 프린터 드라이버가 PC에 설치되어 있는지 확인해 주세요.
   드라이버 설치 및 USB 케이블 연결 후 상단 우측의 새로고침(🔄)을 누르시면 감지됩니다.

Q. 라벨 위치가 한쪽으로 밀려 나오거나 간격이 안 맞아요!
A. 상단 [⚙️ 프린터 설정] > [📏 용지센싱]을 누르면 프린터가 용지 간격을
   자동으로 인식하여 정상 정렬됩니다. (새 용지 장착 시 필수)

Q. 바코드가 흐리거나 스캐너가 인식을 못해요!
A. [⚙️ 프린터 설정]에서 인쇄 농도(Darkness)를 10~12 정도로 올려주세요.

Q. 엑셀 파일이 열리지 않아요!
A. 현재 Excel 프로그램에서 해당 파일을 열어두고 계신 경우 닫은 후 다시 시도하시거나,
   엑셀에서 "다른 이름으로 저장" > "Excel 통합 문서 (*.xlsx)"로 다시 저장해 주세요.

Q. 프로그램이 업데이트되었을 때 기존 라벨 서식이나 설정을 그대로 유지하려면 어떻게 하나요?
A. 다음 두 가지 방법 중 편한 방법을 선택하시면 기존 설정이 100% 그대로 유지됩니다:
   ① [가장 추천] 다운받은 압축 파일 내의 실행파일(LabelMaster.exe)만 기존 폴더로 복사/덮어쓰기 합니다.
   ② [새 폴더 사용 시] 기존 프로그램 폴더 내 [Info] 폴더의 'app_settings.json' 파일을 복사하여
      새 프로그램 폴더의 [Info] 폴더 안에 덮어쓰기 하시면 이전 서식과 프린터 설정이 그대로 복원됩니다.
   (※ 프로그램 내 [ℹ️ 프로그램 정보] 창에서 [📁 현재 프로그램 Info 폴더 열기] 버튼을 누르시면 바로 해당 폴더가 열립니다)
