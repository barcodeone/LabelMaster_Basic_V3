🏷️ LabelMaster (라벨마스터) 공식 사용자 매뉴얼

TSPL 프린터 전용 라벨 디자인 및 대용량 엑셀(Excel) 자동 출력 솔루션 가이드입니다.

버전: v1.0.1 (WPF Modern Edition) 공급사: 한국Xprinter (Xprinter Korea) 지원 OS: Windows 10 / 11 (32·64bit)

1.1 프로그램 소개 및 주요 사양

LabelMaster (라벨마스터)는 TSPL 열전사/감열 바코드 라벨 프린터를 위한 전문 라벨 인쇄 및 대용량 엑셀(Excel) 자동 연동 소프트웨어입니다.

⚠️
[필수 사전 작업] Xprinter 공식 Windows 프린터 드라이버 설치 필수:
프로그램을 실행하기 전, PC에 사용 중인 Xprinter 모델의 공식 Windows 드라이버가 반드시 설치되어 있어야 합니다.
드라이버가 설치되어 있지 않으면 Windows 및 본 프로그램에서 프린터를 인식하지 못하여 목록에 나타나지 않습니다.

✨ 핵심 기능

  • 1:1 실시간 인터랙티브 WYSIWYG 미리보기: 실제 용지 비율로 확인 및 드래그 편집
  • 단건 즉시 입력 모드: 1~8개 항목 타이핑 즉시 출력
  • 엑셀 대용량 연동: 드래그 & 드롭 열기 및 컬럼 매핑
  • 바코드 7종 지원: QR, CODE128, EAN-13, CODE39 등
  • 디자인 템플릿(.lbm): 원클릭 서식 저장 및 복원

💻 시스템 요구사양

  • 운영체제: Windows 10, Windows 11 (32/64-bit)
  • 프레임워크: Microsoft .NET Framework 4.8 이상
  • 필수 드라이버: Xprinter 공식 Windows 드라이버 설치 필수
  • 지원 프린터: Xprinter TSPL 라벨 프린터 전 기종 (XP-T265B, XP-DT326B, XP-D4601B, XP-D4602B, XP-D4604B, XP-D461B, XP-423B, XP-P423B, XP-T4501B, XP-T428B 등)
  • 통신 방식: USB 케이블 (권장), 유선 LAN, Bluetooth

1.3 프린터 연결 및 실시간 상태 확인

💡
[연결 순서 안내] 드라이버를 먼저 설치해야 프린터가 감지됩니다:
1. 프린터 전원을 켜고 PC와 USB 케이블로 연결합니다.
2. Xprinter 공식 Windows 프린터 드라이버를 PC에 설치합니다. (Windows '프린터 및 스캐너'에 모델명이 등록되어야 함)
3. LabelMaster 프로그램을 실행하면 상단 [🖨️ 프린터 선택] 드롭다운에 장치가 자동으로 감지되어 선택됩니다.

프로그램 실행 시 연결된 Xprinter를 자동 감지합니다. 상단 헤더의 상태 배지를 통해 연결 상태를 즉시 확인하세요.

상태 배지 표시 문구 상태 설명 및 조치 방법
🟢 정상 연결 인쇄 준비 완료 프린터와 정상 통신 중이며 라이선스 인증이 완료되어 모든 인쇄가 가능합니다.
🔴 미연결 프린터 미연결 USB 케이블 연결 또는 전원 상태를 확인하고, 상단 버튼을 누르세요.
🟡 미인증 미인증 프린터 한국Xprinter 정품 인증이 확인되지 않아 출력이 제한됩니다. 기술지원팀에 문의하세요.

2.1 라벨 용지 규격(너비/높이 mm) 설정 및 회전

정확한 인쇄를 위해 현재 장착된 라벨지의 실제 규격을 mm 단위로 입력합니다.

1

용지 너비 & 높이 입력

좌측 상단의 [📄 용지 너비]와 [높이]에 라벨 스티커의 실제 크기를 mm 단위로 입력합니다. (예: 80 × 50 mm, 50 × 30 mm 등). - / + 버튼으로 1mm씩 정밀 조정할 수 있습니다.

2

라벨 회전 (90° 회전 버튼)

우측 상단의 버튼을 클릭할 때마다 0° → 90° → 180° → 270° 순으로 회전합니다. 용지의 급지 방향이나 인쇄 형태에 맞추어 자유롭게 변경하세요.

💡
여백 팁: 용지 크기 변경 즉시 1:1 미리보기 캔버스의 흰색 영역이 실제 종이 크기로 실시간 갱신됩니다.

2.2 용지 타입에 따른 센서 설정 (GAP / BLINE / CONTINUOUS)

장착한 라벨 용지의 형태에 맞추어 올바른 센서를 지정해야 라벨이 밀리지 않고 정확한 위치에 멈춥니다.

용지 타입 센서 선택 특징 및 세부 파라미터 설정법
일반 롤 라벨지
(갭 라벨)		 GAP (간격) • 라벨과 라벨 사이에 2~3mm의 투명 간격(Gap)이 있는 표준 용지입니다.
• 설정값: 간격: 2~3 mm (기본 3mm 권장)
블랙마크 라벨지
(흑색 띠 용지)		 BLINE (블랙마크) • 용지 뒷면에 검은색 사각형/라인 마크가 인쇄된 용지입니다.
• 설정값: 마크 높이: 2~3 mm + 표시 오프셋(이탈량): mm 입력
연속 용지
(영수증지 / 무간격)		 CONTINUOUS • 간격이나 블랙마크가 없는 연속 롤 용지입니다.
• 지정한 높이(mm)만큼 인쇄 후 바로 다음 위치에서 멈춥니다.
⚠️
새로운 용지 장착 시 필수 작업 (센서 캘리브레이션):
용지 롤을 교체한 후에는 반드시 상단 > [📏 센서 보정 (캘리)] 버튼을 클릭하세요. 프린터가 용지 2~3장을 자동으로 이송하며 간격을 자동 측정합니다.

2.3 감열(Direct Thermal) vs 열전사(Thermal Transfer - 리본) 인쇄 방식 설정

프린터의 헤드 가열 방식 및 리본(먹지) 장착 여부에 따라 모드를 정확히 선택해야 선명하고 깨끗하게 인쇄됩니다.

🔥 감열 인쇄 방식 (Direct Thermal)

리본 체크 해제

  • 사용 용지: 감열 라벨지 (손톱으로 긁었을 때 검은 선이 생기는 종이)
  • 리본(먹지): 사용하지 않음 (불필요)
  • 주요 용도: 택배 송장, 유통기한 짧은 신선식품 가격표, 배달 영수증
  • 설정: 열전사 (리본 사용) 체크박스 [해제]

🎀 열전사 인쇄 방식 (Thermal Transfer)

열전사 (리본 사용) 체크

  • 사용 용지: 아트지, 유포지, 은무데드롱지, 페트(PET) 라벨
  • 리본(먹지): 왁스(Wax), 레진(Resin) 롤 리본 장착 필수
  • 주요 용도: 제조업 제품 명판, 장기 보관 자산 라벨, 물류 파렛트
  • 설정: 열전사 (리본 사용) 체크박스 [체크]

2.4 1:1 WYSIWYG 캔버스 조작 & 마우스 드래그 폭(너비) 조절

좌측 미리보기 캔버스는 실제 라벨 용지 비율을 1:1로 시뮬레이션하며, 마우스를 이용해 자유롭게 요소를 배치하고 줄바꿈 너비를 조절할 수 있습니다.

🖱️ 마우스 드래그 위치 이동 (Free Move)

  • 텍스트(1~8열), 바코드, 순번, 날짜/시간 요소를 마우스 좌클릭으로 잡고 원하는 위치로 끌어다 놓습니다.
  • 화면 상단의 정렬 도구(좌측/중앙/우측 정렬, 가로/세로 균등 배분)를 활용하면 오차 없이 칼각 정렬이 가능합니다.
  • 방향키(← → ↑ ↓)를 누르면 1픽셀씩 정밀 미세 이동할 수 있습니다.

↔ 우측 크기 조절 핸들 (줄바꿈 폭 제어)

  • 캔버스에서 순번, 날짜/시간 또는 텍스트 항목을 선택하면 우측 테두리에 파란색 크기 조절 핸들이 나타납니다.
  • 핸들을 마우스로 잡고 좌우로 드래그하여 박스 너비(줄바꿈 폭)를 실시간으로 직관 제어할 수 있습니다.
  • 너비가 0(기본값)일 때는 한 줄로 자동 정렬되며, 사용자가 드래그하여 너비를 지정하면 해당 폭에 맞춰 긴 텍스트가 자연스럽게 자동 줄바꿈됩니다.
💡
줄바꿈 및 이모지 안전 렌더링:
순번이나 날짜/시간에 이모지(🕒, 🔢)가 포함되어도 박스가 좁아서 두 줄로 내려앉는 현상이 없도록 자동 계산 여백이 기본 적용되어 있습니다.

3.1 단건 라벨 즉시 입력 및 인쇄 (Tab 1)

급하게 1~2장의 라벨을 출력하거나 샘플을 인쇄할 때 사용하는 가장 빠른 모드입니다.

1

항목 내용 입력 & 줄바꿈

1열~8열 텍스트 상자에 원하는 내용을 입력합니다.
• Enter: 다음 입력칸으로 포커스 이동
• Shift + Enter: 한 칸 안에서 여러 줄 줄바꿈(개행) 입력

2

옵션 지정 (제목출력 / 고정)

• [제목출력] 체크: 항목명(예: "상품명: ", "단가: ")을 내용 앞에 함께 출력합니다.
• [고정] 체크: 인쇄가 끝난 후에도 해당 칸의 텍스트가 지워지지 않고 유지됩니다.

3

인쇄 매수 설정 & 출력

하단의 [인쇄 매수]를 지정(기본 1매)한 후 버튼을 누르거나 Enter 키를 누르면 즉시 인쇄됩니다.

3.2 엑셀(Excel) 대용량 연동 인쇄 (Tab 2)

기존에 사용하시던 엑셀 파일(`.xlsx`, `.xls`, `.csv`)의 수백~수천 개 데이터를 한 번에 불러와 순차 출력합니다.

권장 엑셀 파일 구조 예시

A열 (바코드) B열 (품명) C열 (규격) D열 (판매단가) E열 (비고)
8801234567890 프리미엄 텀블러 500ml 화이트 25000 국산 / 친환경
8801234567891 스텐 보온병 1000ml 블랙 38000 이중진공
💡
엑셀 작성 팁:
1. 1행은 반드시 컬럼 제목(헤더)으로 작성해주세요.
2. 가격/단가는 25000처럼 숫자만 입력하면 프로그램의 [₩금액] 옵션을 통해 ₩25,000으로 자동 변환됩니다.

엑셀 파일 불러오기 2가지 방법

방법 1: 마우스 드래그 & 드롭 ⭐ 강력 추천

탐색기에서 엑셀 파일(`.xlsx`)을 마우스로 잡고 LabelMaster 프로그램 창 안으로 끌어다 놓으면(Drag & Drop) 즉시 엑셀 가져오기 창이 열립니다.

방법 2: 버튼 클릭

우측 상단의 버튼을 클릭하여 파일 탐색기에서 원하는 엑셀 파일을 선택합니다.

3대 인쇄 방식 (선택 / 구간 / 전체)

인쇄 버튼 동작 설명
목록에서 마우스로 클릭하여 파랗게 선택한 행 또는 좌측 체크박스에 체크한 데이터만 골라서 인쇄합니다.
하단 구간 설정창에 지정한 번호(예: 10 ~ 50) 범위의 데이터를 연속 인쇄합니다.
불러온 엑셀의 1번 행부터 마지막 행까지 전량을 일괄 연속 인쇄합니다.

3.3 엑셀 컬럼 매핑 다이얼로그 (Excel Import Dialog)

엑셀 파일을 열면 나타나는 컬럼 매핑 창에서 엑셀의 어떤 열을 라벨의 몇 번 항목에 인쇄할지 지정합니다.

1

워크시트(탭) 선택

엑셀 파일 내에 시트가 여러 개인 경우 상단 드롭다운에서 인쇄할 시트를 선택합니다.

2

항목 1~8번에 엑셀 컬럼 지정

라벨 항목 1번(예: 품명), 2번(예: 단가), 3번(예: 바코드)의 콤보박스를 눌러 매칭할 엑셀 열을 선택합니다.
• : 엑셀의 1~8열을 순서대로 자동 매핑합니다.
• : 이전에 작업했던 엑셀 매핑 설정을 그대로 다시 불러옵니다.

3

매핑 기억 옵션 및 완료

하단의 [엑셀 불러올 때 마지막 매핑 정보 기억 및 자동 적용]을 체크해두면 다음부터 엑셀을 열 때 자동으로 컬럼이 매칭됩니다. [✔️ 데이터 가져오기]를 클릭하면 완료됩니다.

4.1 라벨 서식 & 디자인 편집기 (글꼴 / 바코드 / 금액 서식)

상단 헤더의 버튼을 누르면 항목별 디자인 창이 열립니다.

🔤 글꼴 & 스타일 설정

  • 글꼴(Font): 맑은 고딕, 돋움, Arial, Courier New 등 PC에 설치된 모든 폰트 지원
  • 글자 크기: - / + 버튼으로 1pt씩 미세 조정
  • 스타일: B 굵게(Bold), I 기울임(Italic) 토글
  • 행 높이: 표 모드 사용 시 각 행의 높이 지정 (0은 자동 균등)

🏷️ 바코드 & 금액 자동 서식

  • 💰 금액(₩) 체크: 숫자를 입력하면 자동으로 원화 기호(₩)와 3자리 천 단위 콤마(,)가 적용됩니다. (예: 15000 → ₩15,000)
  • 🏷️ 바코드 체크: 해당 항목의 데이터를 1D/2D 바코드로 출력합니다.
  • 바코드 타입: QR_CODE, CODE_128, EAN_13, CODE_39, ITF, DATA_MATRIX, PDF_417
  • 값 표시 체크: 바코드 아래에 사람이 읽을 수 있는 숫자/문자(HRI) 출력 여부

4.2 표(Table) 테두리 격자 & 순번(Serial) / 날짜(DateTime) 서식 설정

서식 편집기 하단의 [⚙️ 추가 디자인 & 상세 서식 설정]을 펼치면 표와 일련번호, 날짜/시간의 폰트 및 서식을 완벽하게 커스텀할 수 있습니다.

📐 표(Table) 테두리 격자 설정

  • 📐 표 적용 체크: 라벨 전체에 깔끔한 표 격자를 생성합니다.
  • 방향: 세로형(헤더 좌측 / 내용 우측) 또는 가로형(헤더 상단 / 내용 하단)
  • 형태: 전체 격자, 외곽 박스만, 가로선만
  • 두께: 1 pt ~ 5 pt 선 두께 조절
  • 표 상단 제목: 표 위에 큰 제목(예: "제품 검사 성적서", "가격표")과 구분선 출력

🔢 순번(Serial) 자동 일련번호 인쇄

  • 🔢 순번 인쇄 체크: 라벨마다 1씩 증가하는 일련번호를 자동 인쇄합니다.
  • 양식(8종): 1, 2, 3 / 01, 02 / 001 / 0001 / No.1 / #01 / [1] / (001)
  • 방향 / 시작값: 증가(+) 또는 감소(-), 원하는 시작 번호 지정
  • 서식 제어: 글꼴(Font), 글자 크기(-/+), 굵게(B), 기울임(I) 독립 설정

🕒 실시간 날짜/시간(DateTime) 인쇄 서식

  • 🕒 날짜/시간 인쇄 체크: 인쇄 시점의 현재 날짜 또는 시간을 라벨에 자동 출력합니다.
  • 날짜 포맷: YYYY-MM-DD, YYYY.MM.DD, YY/MM/DD, HH:mm:ss 등 다양한 형식 지원
  • 서식 제어: 시스템 글꼴 드롭다운, 글자 크기 증감, 굵게/기울임 토글, 실시간 포맷 미리보기 배지 제공
  • 폭(줄바꿈) 조절: 캔버스에서 마우스 우측 크기 조절 핸들을 드래그하여 원하는 폭 지정 가능

4.3 서식 템플릿 파일(*.lbm) 저장 및 불러오기

공들여 만든 라벨 디자인(용지 크기, 폰트, 바코드, 표 설정, 금액 서식)을 템플릿 파일로 저장해 두고 언제든 1초 만에 불러올 수 있습니다.

1

템플릿 저장 ()

서식 편집기 상단 우측의 [💾 템플릿 저장]을 클릭하고 원하는 파일명(예: 가격표_80x50.lbm, 물류바코드_100x100.lbm)으로 저장합니다.

2

템플릿 불러오기 ()

작업 용도가 바뀔 때 [📁 템플릿 불러오기]를 눌러 저장해 둔 .lbm 파일을 선택하면 모든 디자인 레이아웃이 즉시 복원됩니다.

💡
자동 저장 기능: 마지막으로 작업하던 라벨 디자인과 용지 크기는 프로그램을 종료해도 PC에 자동 저장되어 다음 실행 시 그대로 유지됩니다.

5.1 프린터 하드웨어 설정 (속도 / 농도 / 오프셋 보정)

상단 헤더의 창에서 하드웨어 스펙을 세밀하게 제어합니다.

설정 항목 권장값 상세 설명 및 가이드
인쇄 속도 (Speed) 3~4 inch/sec 숫자가 낮을수록 천천히 정밀하게 인쇄되어 바코드 인식률이 높아지며, 높을수록 대량 출력 속도가 빨라집니다.
인쇄 농도 (Darkness) 농도 8~12 열전사 헤드의 열 온도를 1~15단계로 조절합니다. 글씨가 흐리면 농도를 올리고, 너무 번지거나 리본이 달라붙으면 농도를 낮추세요.
위치 보정 (X, Y 오프셋) X: 0mm / Y: 0mm 라벨 인쇄 위치가 한쪽으로 쏠릴 때 mm 단위로 미세 이동합니다.
• X: 양수(+) 우측 이동, 음수(-) 좌측 이동
• Y: 양수(+) 아래로 이동, 음수(-) 위로 이동
인쇄 후 작업 (커터/뜯기) TEAR (기본) 자동 컷팅 칼날이 장착된 모델은 CUTTER를 선택하여 매 페이지 또는 작업 완료 후 자동 절단을 수행할 수 있습니다.

5.2 하드웨어 유지보수 유틸리티 도구

프린터 하드웨어 설정창 좌측 하단에서 원클릭으로 유지보수 명령을 실행할 수 있습니다.

📄 라벨 1장 배출 (FEED)

프린터에서 용지를 정확히 1장 앞으로 밀어내어 센서 정렬 상태를 테스트합니다.

📏 센서 보정 (캘리브레이션)

용지 간격 센서를 자동 측정하여 라벨 위치 오차를 완전히 잡습니다. (용지 교체 시 필수)

🎯 테스트 인쇄 & 프린터 정보

현재 설정된 디자인으로 1장 샘플을 인쇄하거나, 프린터의 펌웨어 및 내부 스펙 정보(Self-Test)를 출력합니다.

🔄 리셋 & ⚠️ 공장 초기화

프린터를 소프트웨어적으로 재부팅하거나, 모든 설정을 공장 출하 초기 상태로 포맷합니다.
